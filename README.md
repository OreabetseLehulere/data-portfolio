# Data Analytics Portfolio

A collection of data analysis and data engineering projects built with Python.

## Projects

### 1. Financial News Sentiment Analyzer
Pulls live financial news headlines from NewsAPI and automatically 
scores each headline as Positive, Negative or Neutral using NLP.

**Technologies:** Python, Pandas, NLTK, Matplotlib, SQLite, NewsAPI

**Features:**
- Live news fetching via API
- Automated sentiment scoring
- Daily sentiment trend charts
- Excel report export
- SQLite database storage

---

### 2. Crypto Price Tracker
Tracks live cryptocurrency prices for Bitcoin, Ethereum and BNB.
Triggers alerts when prices cross set thresholds.

**Technologies:** Python, Pandas, Matplotlib, SQLite, CoinGecko API

**Features:**
- Live price fetching with no API key required
- Customizable price alerts
- 24h change visualization
- Price history database
- Excel report export

---

### 3. JSE Stock Analyzer
Analyzes live Johannesburg Stock Exchange stock prices including 
Naspers, Anglo American, Sasol, Standard Bank and MTN.

**Technologies:** Python, Pandas, Matplotlib, SQLite, yfinance

**Features:**
- Live JSE stock prices in ZAR
- 52 week high/low analysis
- Distance from high calculation
- Stock comparison charts
- Excel report export

---
